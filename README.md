# Fuzzy-Superpixel-based-Image-Segmentation

This repository will host the complete source code and implementation details of my M.Tech dissertation:

**Title**: Designing Superpixel-Based Multi-Resolution Model for Enhanced Object Delineation  
**Author**: Ali Shash  
**Institute**: Indian Institute of Technology (ISM), Dhanbad  
**Submission Date**: May 2025

## 📌 About the Project

This work proposes a novel image segmentation framework that integrates fuzzy C-Means clustering, graph-based hierarchical segmentation, and multi-resolution wavelet analysis. It aims to improve object boundary precision in complex and low-contrast images.

## 🧠 Key Features

- Superpixel decomposition using fuzzy logic and LAB + texture + spatial features
- Affinity graph construction with spatial intersection and visual dissimilarity
- Hierarchical Normalized Cuts for segmentation refinement
- Multi-resolution fusion with morphological filtering

## 🔧 Tools & Libraries

- Python, NumPy, SciPy, OpenCV, scikit-image
- Matplotlib, PyWavelets, NetworkX
